# Иллюстрации / Illustrations

Положи сюда картинку с именем слота — она автоматически заменит Notion-заглушку.
Drop an image named after a slot here and it replaces the placeholder art automatically.

Форматы / formats: `.svg` `.png` `.webp` `.avif` `.jpg`, анимация / animation: `.mp4` (+ `.webp` стоп-кадр / still)

| Слот / slot | Где / where                         | Пропорции / ratio | Сейчас / now                 |
|-------------|-------------------------------------|-------------------|------------------------------|
| `hero`      | первый экран, справа                | 6:5               | глобус в ладонях             |
| `privacy`   | карточка «Приватность по умолчанию» | 400:260           | замок с отпечатком           |
| `devices`   | карточка «Все устройства»           | 400:260           | ноутбук с лампой             |
| `support`   | карточка «Поддержка 24/7»           | 400:260           | телефонная трубка            |
| `step-1`    | «Как это работает», шаг 1           | 400:260           | конверт с купонами-скидками  |
| `step-2`    | «Как это работает», шаг 2           | 400:260           | рука листает экран           |
| `step-3`    | «Как это работает», шаг 3           | 400:260           | ракета                       |
| `faq`       | блок FAQ и страница FAQ             | 4:3               | человек со знаком вопроса    |
| `cta`       | блок «Готов начать?»                | 440:300           | победитель в кубке           |
| `legal`     | шапка страницы «Документы»          | 4:3               | коробка с документами        |

Пример / example: `hero.svg`, `step-1.png`.

## Анимации / Animations

`<slot>.mp4` — рисунок тушью и акварелью на белом фоне; белый «растворяется» через `mix-blend-mode`,
в тёмной теме кадр инвертируется (см. `src/components/illustration.tsx`). `<slot>.webp` — стоп-кадр для
«уменьшить движение» и для заблокированного автозапуска (режим энергосбережения iOS).

Их делает `scripts/encode-illustrations.py` из исходников в `design/illustrations/` (в git не лежат — 34 МБ):
обрезка, уменьшение, перекраска оранжевого в цвет бренда, сжатие. Нужны `ffmpeg` и `numpy`.

The `.mp4`/`.webp` pairs are generated by `scripts/encode-illustrations.py` from the sources in
`design/illustrations/` (not in git): crop, downscale, recolor to the brand pink, compress.
