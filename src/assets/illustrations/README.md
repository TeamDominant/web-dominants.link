# Иллюстрации / Illustrations

Положи сюда картинку с именем слота — она автоматически заменит Notion-заглушку.
Drop an image named after a slot here and it replaces the placeholder art automatically.

Форматы / formats: `.svg` `.png` `.webp` `.avif` `.jpg`

| Слот / slot | Где / where                         | Пропорции / ratio |
|-------------|-------------------------------------|-------------------|
| `hero`      | первый экран, справа                | 6:5               |
| `privacy`   | карточка «Приватность по умолчанию» | 400:260           |
| `devices`   | карточка «Все устройства»           | 400:260           |
| `support`   | карточка «Поддержка 24/7»           | 400:260           |
| `step-1`    | «Как это работает», шаг 1           | 400:260           |
| `step-2`    | «Как это работает», шаг 2           | 400:260           |
| `step-3`    | «Как это работает», шаг 3           | 400:260           |
| `faq`       | блок FAQ и страница FAQ             | 4:3               |
| `cta`       | блок «Готов доминировать в сети?»   | 440:300           |

Пример / example: `hero.svg`, `step-1.png`.
